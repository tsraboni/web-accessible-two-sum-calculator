How to Use

1. Enter a number in the Add a Number box.

2. Click Add Number to add it to the array.

3. Click Remove Last Number to remove the last value in the array.

4. Enter a number in the Target box.

5. The solver will look for two numbers that add up to the target.

6. The result will show the indices and the two matching numbers.
